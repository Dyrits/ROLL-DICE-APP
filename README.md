# Roll Dice App

A very simple app that rolls a dice when the user presses a button, built with Flutter.

## About The Project

A Flutter dice-rolling app, with targets for Android, iOS, web, Linux, macOS and Windows.

## Built With

- Flutter / Dart

## Getting Started

Install [Flutter](https://docs.flutter.dev/get-started/install), fetch the dependencies with `flutter pub get`, then run the app with `flutter run`.
